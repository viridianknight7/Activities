# Legendary Devil Fruit Trees V31 — Ancient Titans

Exactly three independent, genuinely volumetric polygonal world-tree sculptures: Zoan, Logia and Paramecia. V31 makes the tree anatomy enormous and joined, instead of the earlier Sudowoodo/twig appearance. It keeps a mostly text-free mobile scene and a complete inherited 146-entry Devil Fruit catalogue.

Open the [self-contained HTML](index.html), or use the browser preview at https://raw.githack.com/viridianknight7/Activities/main/devil-fruit-trees/v31/index.html

Finger-swipe across the main scene to change tree class; tap the tree to explore; drag to orbit; pinch or scroll to zoom; tap a hanging 3D fruit to see its catalogue record. Only requested fruit information and a narrow temporary family chooser contain text.

There are 44 Zoan, 12 Logia and 90 Paramecia entries in 19 groups, three hanging fruits per page. This catalogue was inherited from the earlier version; canon accuracy is not independently verified. Fruit sculpting is not yet uniquely accurate for every record.

The project is a working intermediate prototype, **not yet an artistically approved legendary tree experience**. Browser screenshots used the same three-dimensional meshes through the Canvas2D software renderer because the test browser's native WebGL was unavailable. Actual Android WebGL performance is unverified.

Read the permanent [design, QA and continuation plan](GAMEPLAN.md) and [machine-readable QA report](QA_REPORT.json). The downloadable ZIP attached in the originating ChatGPT conversation includes the exact offline HTML, authored art source, tests, catalogue JSON and 20 actual browser screenshots.
