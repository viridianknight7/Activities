# The Three Legendary Trees — Rebirth

A scratch-built interactive 3D Devil Fruit encyclopaedia featuring exactly three independent chibi-low-poly trees.

Open [the standalone website](index.html) or the browser preview at https://raw.githack.com/viridianknight7/Activities/main/devil-fruit-trees/rebirth/index.html

The HTML is self-contained and can be downloaded and opened offline; no external JavaScript or CSS dependencies. Supported browsers use native WebGL; a Canvas2D renderer projects the same true 3D triangle meshes when WebGL is disabled. Drag to orbit, wheel or pinch to zoom, tap a hanging fruit for its specific record, browse family pages, and search the 146-entry catalogue.

The classes have 44 Zoan, 12 Logia, and 90 Paramecia fruit records across 19 families. Data was preserved from the inherited structured catalogue; tree shapes, mesh engine, interfaces and palettes are newly authored. The full source ZIP in the originating ChatGPT conversation includes editable app.js, style.css, fruit-data.json, ten browser screenshots and local QA scripts.

Read [the permanent build and continuation plan](GAMEPLAN.md). The project remains visually unfinished compared with the requested legendary art standard. Its current strengths are an original clean geometry foundation, working 3D orbit and functional encyclopaedia navigation. The canonical status of inherited lore and physical Android WebGL have not been independently verified.
