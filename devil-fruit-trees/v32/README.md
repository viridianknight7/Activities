# Legendary Devil Fruit Trees V32 — Crown Rebuild

Exactly three three-dimensional macro-chibi, flat-faceted Devil Fruit trees: Zoan, Logia and Paramecia. A new independently authored set of physical foliage tiers has replaced the single rounded-cloud crowns from V31. The resting mobile view remains text-free and finger-first.

Open [index.html](index.html) (a self-contained offline browser application) or try the [external browser preview](https://raw.githack.com/viridianknight7/Activities/main/devil-fruit-trees/v32/index.html). The GitHub repository copy is verified; external preview caching is a separate question.

Swipe sideways to change class, tap to explore, drag to orbit, pinch or wheel to zoom, tap one of the three hanging fruits to open its details. Family and catalogue panels open only on demand.

The inherited catalogue contains 146 entries (44 Zoan, 12 Logia, 90 Paramecia), grouped in 19 families. The app passed 146/146 details checks, five viewport sizes, 20 canonical screenshot states and nine closer art-diagnostic views, with no JavaScript errors. The exact package in the originating ChatGPT conversation includes editable art32.js, test scripts, fruit-data.json, QA_REPORT.json and all 29 actual screenshots.
