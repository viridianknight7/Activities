# Legendary Devil Fruit Trees V29

One genuinely 3D chibi-poly tree per Devil Fruit class, with a minimal finger-first mobile interface. This version preserves the inherited 146 records (44 Zoan, 12 Logia, 90 Paramecia) and 19 families.

Open the [standalone webpage](index.html), or preview it at https://raw.githack.com/viridianknight7/Activities/main/devil-fruit-trees/v29/index.html. Downloading index.html allows offline opening; the application has no remote JavaScript dependencies.

Swipe to switch trees, tap a tree to explore, drag to orbit, pinch or wheel to zoom, tap a hanging fruit for its record, and use the compact on-demand catalogue search. Three fruits appear per family page.

This is an intermediate 3D sculptural revision, **not a finished legendary visual design**. See the permanent [GAMEPLAN.md](GAMEPLAN.md) and [QA_REPORT.json](QA_REPORT.json). The source package attached in the originating ChatGPT conversation contains the editable art module, preserved JSON, tests, 10 standard screenshots and the full 16-view audit.

The automated renders used Canvas2D software 3D because WebGL was unavailable in the test browser. Physical Android GPU performance and inherited canon accuracy are still unverified.
