# Legendary Devil Fruit World V30

A dependency-free, fully orbitable WebGL Devil Fruit encyclopaedia created **exclusively from the verified V29 reference rebuild**. This version keeps the exact historical 146-record dataset in 19 families, four finger-navigated exploration stages and exactly one redesigned three-dimensional model per class.

Zoan is now a broad ancient oak with a **completely face-free** trunk. No animal eyes, muzzle, ears or mask. It has wide layered faceted green crowns, muscular orange roots and two asymmetric antique-gold lunar-growth cambium arcs organically attached to separate wooden boughs. Logia is a cohesive volcanic organism with connected orange fire, purple storm, cyan glacier, ice wind and glowing bark seams. Paramecia uses intertwined ivory and pink stems, deep layered sakura/lotus crowns, two cosmic rings and a rooted violet portal. Each model has a distinct stone/grass island and physical waterfalls.

**Touch:** tap a tree, one highlighted family and then a fruit. Fast horizontal swipe changes trees, families or fruits; slow dragging orbits the 3D camera; pinch zooms. Small icon-only Back/Previous/Next controls and desktop keyboard/wheel access remain. On-screen copy is limited to the selected class/family/fruit and the eight encyclopaedia fields, not explanatory labels or UI cards.

**Run:** open `index.html` in a WebGL-capable browser; no network needed. The standalone page includes the shader engine, three sculptures, all fruit meshes and catalogue data.

**Rebuild:** run `python build.py` from this directory. Modules: `template.html`, `styles.css`, `data.json`, `geometry_engine_from_v23.js`, `geometry25.js`, `geometry26.js`, `geometry27.js`, `geometry28.js`, `geometry29.js`, `geometry30.js`, `app.js`. The module reconstruction is checked against the exact published standalone HTML.

**QA:** Local tests rendered WebGL in Chromium SwiftShader at 390×844 and 1440×900. All 146 detail screens, 19 groups, eight factual fields, touch/swipe/orbit/zoom, Back/Next/Previous, a complete fourteen-shot diagnostic screenshot set, and desktop renders passed with no uncaught JS exceptions. The downloadable source ZIP contains `qa_v30.py`, the 14 PNGs, `V30_fourteen_diagnostic_views.png`, and `V30_reference_V29_V30_comparison.png`.

**Limitations:** Your three painted references are not source 3D models. V30 is a three-dimensional *interpretation*, not studio-exact. It needs professionally sculpted geometry and material art before an award-fidelity claim. The 146 fruits are inherited historical project records rather than audited current canon. Only 23 entries are historically marked illustrated and those forms remain stylised; 123 are sealed appearance-unknown. Real Android performance and the external CDN preview host have not been independently verified.
