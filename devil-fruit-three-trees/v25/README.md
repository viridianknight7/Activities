# Legendary Devil Fruit Trees V25

Interactive, standalone, **single-page WebGL Devil Fruit encyclopaedia** using oversized macro-chibi polygonal art. Derived from V24. Contains exactly one original sculptural tree per class and preserves the historical 146-fruit catalogue and 19 physical hanging families. Mouse/touch orbit; tap a tree, then a family, then a fruit. Previous/Next and Back navigate without reloading.

**Models:** Zoan Beast Grove, Logia Elemental Confluence, Paramecia Possibility Nexus. Three volumetric sculptures, a shared floating-island language, procedural illuminated fruit models, anonymous chained black locks for unverified appearances.

**Files:** `index.html` contains the entire game and runs independently, `geometry_engine_from_v23.js` is the inherited V24 engine, `geometry25.js` contains all new 3D models, `app.js` controls navigation and WebGL, `styles.css` controls legibility, `data.json` contains the unchanged catalogue, `template.html` and `build.py` recreate the standalone build, `GAMEPLAN.md` contains the permanent plan, `QA_V25.json` records tests, and `V25_10_screenshot_comparison.png` is the visual QA board.

Run `python build.py` to check a byte-for-byte build. Open `index.html` in a WebGL-enabled browser. The app has no third-party JS dependencies. See the game plan for accepted visual direction and remaining limitations.
