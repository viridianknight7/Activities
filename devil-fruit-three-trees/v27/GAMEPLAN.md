## V27 QA and observed issues (27 November 2026)

The exact baseline V26 received **72% subjective vision match / 84% project completeness**, after reviewing rear/high angles as well as front views. New V27 render dimensions and triangle counts, measured from all mesh vertices: Zoan X45.68 / Y76.36 / Z41.59 (6,435 triangles), Logia X43.56 / Y67.05 / Z36.59 (7,802), Paramecia X45.10 / Y76.95 / Z38.45 (17,458). Z/X 0.91 / 0.84 / 0.85 respectively, exceeding minimum 0.77. No axis is flattened.

**Initial diagnostic failures and repairs:** Initial Zoan foliage looked like thin terraced discs. Increased canopy thickness, reshaped the dome and removed checker-board facet variation. Huge pink family bough dominated the 390px fruit screen; scaled it down to 71% without changing fruit spacing or hit targets. Overly dense Paramecia petal bulbs made the flower silhouettes confused, so removed them. Captured each corrected screen again. Desktop family assertion initially assumed mobile 3-item pagination; fixed the QA to recognise desktop's 5-item page instead, without changing the application.

**Completed checks:** 390×844 and 1440×900 Chromium SwiftShader rendering; deliberate front and elevated/opposed orbits; tree→family→fruit; 146 detail screens with 8 fields each; all 146 unique records, 19 groups and 123 historical unknown/sealed flags; next/back; swipe, slow orbit, wheel and synthetic two-pointer pinch; no uncaught JS runtime errors in either browser. No proof of actual Android GPU performance or external CDN response.

**Design deficits still open:** Zoan leaf lobes and guardian mask can become much more organic; Logia cloud and fire shapes still include familiar procedural primitives; Paramecia petals and spirals need further reference-led hand sculpting; waterfalls viewed from behind can appear detached; exact canon fruit modelling is not complete. The V27 step is a tested, materially improved intermediate version, not a finished canonical art atlas.
