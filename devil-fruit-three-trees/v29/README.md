# Legendary Devil Fruit Trees V29

A dependency-free WebGL Devil Fruit encyclopaedia with exactly one new macro-chibi volumetric tree for Zoan, Logia and Paramecia. This release builds directly on V28, preserves its historical 146 Devil Fruit records and 19 families, and retains minimal-text finger navigation.

Touch a tree to select its hanging fruit families, touch a family to see its fruits, and touch a fruit to inspect. Swipe to switch choices, drag slowly to orbit, pinch to zoom, or use small icon buttons. Fruit inspection shows eight facts. 123 appearances without established designs remain sealed.

Open `index.html` directly in a WebGL-compatible browser. `template.html`, `app.js`, `styles.css`, `data.json` and six geometry scripts are the editable source. Run `python build.py` to rebuild the exact standalone page. The source ZIP supplied with the release contains the full local QA script and ten diagnostic PNG screenshots.

Local Chromium/SwiftShader QA passed at mobile 390 × 844 and desktop 1440 × 900, all 146 details and primary gestures. See `QA_V29.json` and `GAMEPLAN.md`. Canon-exact illustrated fruit appearances, sustained physical Android performance and external preview CDN reachability remain unverified.
