# Legendary Devil Fruit World V32

A dependency-free, standalone WebGL Devil Fruit encyclopaedia, **built exclusively on the verified V31** version and the user's three concept-art references. It retains **146 historical project fruit records**, **19 families**, **three separate fully triangulated tree meshes** and four continuous exploration stages. The page renders locally without third-party JavaScript dependencies.

- **Zoan:** a wide ancient oak; no face or facial elements whatsoever. Two asymmetric antique-gold crescent growth features supported by real boughs, larger interlocked radial foliage and muscular buttress roots.
- **Logia:** a geological spirit tree with joined orange fire, violet storm, branching lightning and 3D ice/wind currents.
- **Paramecia:** ivory-pink braided trunk, spacious deeper sakura crowns, restrained gold rings and a violet portal physically grown from bark.

Each class has its own thick low-poly floating island with connected 3D waterfalls. Fruit families hang from the trees, then open to physical hanging individual fruits and eight-field data inspections. Unknown-appearance fruits retain the conservative chain and lock rather than fabricated official appearances.

**Controls:** tap a tree, hanging family or individual fruit; swipe left/right to cycle; drag slowly to orbit; pinch or wheel to zoom. Small icon-only navigation controls remain as fallbacks. Only factual names and encyclopedia data are on screen, not tutorial/instructional overlays.

**Run:** open `index.html` in a WebGL-enabled browser. **Build:** run `python build.py` to reproduce `index.html` from the `template.html`, `styles.css`, `data.json`, `app.js` and nine geometry modules (from inherited V23 engine through newly authored V32). **Tests:** `qa_v32.py` captures six diagnostic tree angles plus eight UI levels and checks mobile/desktop WebGL interaction; `qa_release_fast.py` repeats the catalogue and geometry tests on the exact final file. The fourteen screenshots, QA report and reference comparison are part of the downloadable package.

**Important limits:** The concept paintings are not complete 3D source models, and the V32 result does not exactly match their studio-grade surface detail. The original 146-record database is inherited historical project data, not a claim that all current manga Devil Fruits are included. Only 23 are historically marked illustrated, in stylised form; 123 remain sealed unknowns. Physical Android FPS and the external RawGitHack CDN are not independently verified.
