# Legendary Devil Fruit Spirit Trees V28

A touch-first, single-file, offline-capable WebGL encyclopaedia with three volumetric low-poly spirit trees. V28 is built solely from the verified V27 version. Zoan is an ancient animal guardian forest, Logia is a natural-force basalt/storm/fire spirit, and Paramecia is an interwoven blossom and portal creature. The world retains 146 historical catalogue entries (44 Zoan / 12 Logia / 90 Paramecia) in 19 families.

Swipe left/right to change the current tree, family or fruit. Tap the three-dimensional world, family light or a fruit to inspect. Drag slowly to orbit and pinch to zoom. Icon-only Back/Previous/Next controls are available. No promotional copy, text tutorial or opaque full-screen menus. Only selected names and actual catalogue data are shown.

The complete application is `index.html`. Editable source modules: `geometry_engine_from_v23.js`, `geometry25.js`, `geometry26.js`, `geometry27.js`, `geometry28.js`, `app.js`, `styles.css`, `data.json`, `template.html`, `build.py`. Run `python build.py` to reproduce the exact standalone HTML. The QA script `qa_v28.py` requires Chromium/Playwright and runs actual software-WebGL browser interaction tests.

The ten diagnostic screenshots show front, rear, opposite and elevated tree geometry plus Tori Tori family attachment, Substance Creation fruit arrangement, Awa Awa illustrated fruit and Numa Numa sealed appearance. `QA_V28.json` records counts and known limitations.

The 146-record historical dataset should not be described as complete current One Piece canon. 23 illustrated fruits remain stylised interpretations, not reference-audited exact appearances; the other 123 have sealed silhouettes. Physical Android GPU performance and the third-party browser-preview URL are unverified in this environment. See `GAMEPLAN.md` for the step-by-step continuation plan.
