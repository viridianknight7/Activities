# Legendary Devil Fruit World V26

A single-file, dependency-free, finger-first WebGL Devil Fruit encyclopaedia, derived from V25, with one genuinely volumetric flat-faceted macro-chibi tree each for Zoan, Logia and Paramecia.

Open `index.html` in a WebGL-capable browser. The page contains all 146 historical fruit records and 19 families. Touch a tree, its highlighted hanging family, and a fruit to inspect. Swipe horizontally to change selections, drag slowly to orbit, and pinch to zoom. Small icon-only buttons provide a fallback; the only prominent text is catalogue data.

The entire renderer, catalogue, geometry, and application are bundled in `index.html`. The ZIP downloadable from the conversation also contains editable `geometry26.js`, inherited mesh engine, source data, template, styles, app logic and reproducible `build.py`.

Mobile and desktop QA: 390×844 and 1440×900 software-WebGL render, six tree angles, four family/fruit templates, all 146 fruit detail screens. See `QA_V26.json` and `GAMEPLAN.md`.

Limitations: source data is a historical project catalogue, not an up-to-date comprehensive canon listing; illustrated fruit sculptures are stylised, not verified replicas; a physical phone performance benchmark and live third-party preview confirmation remain outstanding.
